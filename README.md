# AveSTT — расшифровка аудио и видео в текст

Программа для Windows, которая превращает речь из аудио- и видеофайлов в текст.
Работает **полностью без интернета**: распознавание идёт на вашем компьютере, файлы никуда не отправляются.

## Возможности

- Аудио и видео почти любых форматов: MP3, WAV, M4A, OGG, OPUS, FLAC, WMA, AAC, MP4, MKV, AVI, MOV, WEBM и другие.
- Перетаскивание файлов и целых папок в окно, очередь из нескольких файлов.
- Текст появляется по мере распознавания, видно сколько осталось.
- Автоопределение языка (русский, английский и ещё ~100 языков) или ручной выбор; перевод речи на английский.
- Исправление текста прямо в окне, история всех расшифровок с поиском.
- Сохранение в **TXT, Word (DOCX), субтитры SRT и VTT**, копирование в буфер, отметки времени.
- Светлая, тёмная и системная тема.
- Обновление программы в один клик из настроек.
- Модели на выбор — от быстрой Tiny до точной Large v3. Модель Small встроена, остальные скачиваются один раз.

## Установка

1. Откройте страницу [Releases](https://github.com/imkita339-afk/AveSTT/releases/latest).
2. Скачайте `AveSTT-Setup-x.y.z.exe`.
3. Запустите его и нажимайте «Далее». Права администратора не нужны.

Размер: установщик ~490 МБ, после установки ~770 МБ. Каждая дополнительная модель — от 75 МБ до 3 ГБ
(все модели вместе — около 8 ГБ).

Требования: Windows 10/11, 64 бит, 4 ГБ ОЗУ (для моделей Large — 8 ГБ).

## Для разработчика

Нужны Python 3.12 и [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```bash
py -V:3.12 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python AveSTT.py
```

Полная сборка (exe + установщики в `dist\`):

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

### Выпуск новой версии

1. Поменяйте `__version__` в [app/version.py](app/version.py).
2. Закоммитьте и отправьте тег: `git tag v1.0.1` и `git push origin v1.0.1`.
3. GitHub Actions соберёт релиз с двумя файлами:
   - `AveSTT-Setup-*.exe` — полный установщик со встроенной моделью;
   - `AveSTT-Update-*.exe` — лёгкий установщик без модели, его скачивает встроенное обновление.

Программа проверяет `releases/latest` этого репозитория при запуске (если есть интернет) и по кнопке в настройках.

### Устройство

| Путь | Что там |
|---|---|
| `AveSTT.py` | точка входа, окно на pywebview (Edge WebView2) |
| `app/transcriber.py` | очередь файлов и распознавание через faster-whisper |
| `app/models.py` | каталог моделей и их скачивание (huggingface.co, запасное зеркало) |
| `app/updater.py` | проверка и установка обновлений из GitHub Releases |
| `app/exporters.py` | TXT / SRT / VTT / DOCX |
| `ui/` | интерфейс (HTML/CSS/JS, без внешних зависимостей) |
| `packaging/` | спецификация PyInstaller и скрипт Inno Setup |

Данные пользователя (настройки, история, скачанные модели) лежат в `%LOCALAPPDATA%\AveSTT`.
